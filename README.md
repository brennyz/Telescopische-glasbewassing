# Telescopische glasbewassing

Een ode voor fietsopa Joris en voor de single *Telescopische Glasbewassing* van De Huilende Rappers. Je rijdt een bromscootmobiel langs de gevels, schuift de stok uit en wast de ruiten. De zeep en het scorebord blijven in deze browser.

Dit is een eigen tekening en een eigen tekst. De site bevat geen songtekst en geen audio van het nummer. De officiële single staat op Apple Music, vanuit het odescherm.

## Lokaal draaien

Er is geen installatie en geen build.

1. Clone of download deze map.
2. Open `index.html` in Chrome, Firefox, Safari of Edge.

Dat is genoeg. Het werkt zonder internet. Geluid begint na de eerste klik of tik.

Als een browser een pagina vanaf schijf tegenhoudt, start in deze map een eenvoudige server:

```bash
python3 -m http.server 8000
```

Open daarna http://localhost:8000.

## Besturen

- Schrobben: houd de spatiebalk, de toets K, de straat of de knop Schrobben vast.
- Hoogte van de stok: pijl omhoog en omlaag, of de knoppen Hoog, Midden en Laag.
- Hobbel: houd vast voordat de balk leeg is. Schrobben telt ook.
- Turbo: toets T, als de gekozen stok een turbo heeft.
- Pauze: Esc.

Op een telefoon staat dezelfde duimbalk onder de straat. Draai je het toestel, dan pauzeert de rit.
